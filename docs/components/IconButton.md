# IconButton

Botão redondo só com ícone, para barras de ferramentas do documento (anterior/próximo achado, comparar, comentar).

- `label` é obrigatório: vira `aria-label` e dica.
- `pressed` para alternâncias (modo comparação ligado). Pressionado usa `action`.
- Nunca para a ação principal: essa leva rótulo em texto.
