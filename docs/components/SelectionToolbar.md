# SelectionToolbar

Barra que aparece sobre o texto selecionado: o analista transforma qualquer trecho em pergunta, achado ou comentário.

- Ações padrão: Perguntar ao AAR, Marcar achado, Comentar, Ver na referência.
- Bloco `inverse` para se separar do documento; some com Esc ou clique fora.
- O trecho selecionado entra como contexto no Composer.
