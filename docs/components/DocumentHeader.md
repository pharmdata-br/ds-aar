# DocumentHeader

Cabeçalho do documento em análise: tipo, produto, metadados regulatórios e estado geral.

- `kind` em rótulo ("Bula profissional", "Bula paciente", "Parecer").
- `meta` mostra o que identifica o documento: detentor, registro (`code`), versão, data de publicação.
- Até três `tags` de contexto; `status` resume a análise.
