# StatusTag

O estado de uma seção ou achado, sempre com ícone e rótulo.

- `conforme` (✓, `positive`), `revisar` (!, `warning`), `divergente` (≠, `negative`), `ausente` (∅, tracejado neutro), `analise` (ponto que respira, `action`).
- Conforme e Divergente têm luminância parecida: a forma do ícone carrega a diferença. Nunca troque o ícone.
- `label` personaliza o texto ("Divergente · 2"), não o estado.
