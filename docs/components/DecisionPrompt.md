# DecisionPrompt

Quando a análise precisa do analista: pergunta direta, borda `action` e as saídas possíveis.

- Uma pergunta, respondível com os botões. Detalhe em uma linha.
- Confirmar avança; o secundário mostra os trechos envolvidos no documento; Descartar é opcional.
- Nada sugerido é gravado sem esta confirmação.
