# Button

Botão em pílula com verbo e direção: o próximo passo é sempre explícito.

- `primary` (fundo `action`) para a ação principal da tela ou do achado. Um por bloco.
- `secondary` (contorno `ink`) para a alternativa; `ghost` para ações de baixo peso numa barra; `link` para texto corrido.
- `arrow="forward"` (→) quando avança na análise; `arrow="external"` (↗) quando abre algo fora dela (bula de referência, norma).
- `inverse` só sobre blocos `inverse`.
- Rótulo começa por verbo: "Revisar posologia", "Aprovar achado", "Abrir referência".
- `size="sm"` (44px) dentro de painéis e mensagens; 52px em páginas.
