# Tag

Etiqueta em pílula para vocabulários, fontes e contexto.

- `mist` (padrão): vocabulário, fonte, competência ("EDQM", "Bula de referência").
- `outline`: fonte citada numa resposta.
- `solid` só para o estado escolhido ("Recomendado", "Em dia"); `pending` (tracejado) para o que falta explorar.
- No máximo três visíveis por achado; o resto atrás de "ver fontes".
