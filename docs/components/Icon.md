# Icon

Ícones de traço 2px em `currentColor`, grade de 24, pontas arredondadas.

- Estados: `check` (conforme), `alert` (revisar), `diverge` ≠ (divergente), `absent` ∅ (ausente).
- Documento e interação: `document`, `compare`, `link`, `comment`, `ask`, `flag`, `search`, `filter`, setas e chevrons.
- Decorativo por padrão (`aria-hidden`); passe `label` quando o ícone for o único portador de sentido.
- Não use ícones "de IA" (brilhos, varinhas).
