# SectionHeading

Rótulo-capítulo, título com itálico e uma frase ao lado: a abertura de toda seção.

- `label` em caixa alta nomeia o capítulo ("02 · Posologia"); `title` afirma; `emphasis` é a parte em itálico serifado, em `action`.
- `lead` fica à direita, alinhado pela base, até 460px.
- `level` 1 (56px) para a página, 2 (48px) para seções, 3 (32px) para painéis.
