# Changelog

## 0.1.0 — 2026-11-11

- Primeira versão a partir do design system AAR no claude.ai.
- Tokens em claro e escuro, gerados para CSS e TypeScript.
- 38 componentes React em TypeScript, incluindo a bancada e a costura documento ↔ análise (`AnalysisProvider`).
- Marca adotada: símbolo Trecho marcado, componente `Logo` e SVG em `assets/logos`.
- Documentação: marca e uso, interação documento ↔ análise, stack (Next.js, PostgreSQL, AWS) e um guia por componente.
